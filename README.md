# Traffic Violations Insight System

**Exploratory Data Analysis • Data Cleaning • Interactive Streamlit Dashboard**

Cleans a raw traffic violations export, engineers a few derived features, and
serves the result through an interactive Streamlit dashboard plus a static
EDA report with saved charts.

## A note on the dataset

This project is modeled on the full Montgomery County-style traffic stops
dataset, which includes stop date/time, agency, location, and lat/long. The
`raw_traffic.csv` used here is a **trimmed export that doesn't include those
columns** - it has description, boolean incident flags, state/jurisdiction
codes, vehicle info, and driver demographics, but no date, time, or location
data. That rules out anything involving hotspots, time-of-day, or
weekday/month trends - those questions just aren't answerable with this file.
`clean_data.py` is written so it would pick date/time/geo columns up
automatically if a fuller export were dropped in later, but nothing here
currently depends on them.

## Project Objectives

- Clean and de-duplicate ~70,000 traffic violation records
- Standardize state codes, vehicle makes, and boolean incident flags
- Flag out-of-range vehicle years and invalid state/jurisdiction codes
- Categorize free-text violation descriptions into a fixed set of groups
- Derive an accident-severity indicator from the incident flags
- Explore common violations, demographics, and vehicle involvement in a
  written EDA report with saved charts
- Serve everything through a filterable Streamlit dashboard

## What's Here

| File | Purpose |
|---|---|
| `clean_data.py` | Reads `raw_traffic.csv`, cleans and enriches it, writes `cleaned_traffic.parquet` |
| `eda.py` | Reads the cleaned data, saves charts to `eda_charts/`, writes `EDA_REPORT.md` |
| `app.py` | Streamlit dashboard over the cleaned data |
| `EDA_REPORT.md` | Generated by `eda.py` - written findings with embedded charts |
| `eda_charts/` | Generated by `eda.py` - the PNGs referenced in the report |
| `cleaned_traffic.parquet` | Generated by `clean_data.py` - not committed, regenerate locally |

### Data cleaning (`clean_data.py`)

- Drops full-row duplicates (99 found in the raw export)
- Maps Yes/No/Y/N flags to real booleans, leaving unrecognized values as
  missing rather than assuming "No"
- Uppercases state/jurisdiction codes and nulls out known junk values (`XX`,
  `US`) - Canadian province codes are left alone since those are legitimate
- Blanks out vehicle years outside 1960-2025 (typos like `1013` or
  placeholders like `0`/`9999`)
- Collapses common make abbreviations (`TOYT` → `TOYOTA`, `HOND` → `HONDA`,
  etc.) so one manufacturer doesn't get split across rows in the charts
- Buckets free-text violation descriptions into groups (Speeding, Red Light /
  Signal, Registration / Plate, License / Suspended, Seatbelt, Stop Sign,
  DUI / Alcohol, Other)
- Derives an ordinal `accident_severity` column from the injury/damage/
  contributed-to-accident flags
- Converts low-cardinality text columns to `category` dtype and vehicle year
  to a nullable int, to keep the parquet file small

### EDA (`eda.py`)

Answers the questions the data can support: most common violations, vehicle
types most involved, accident-contribution rate by vehicle type, and how
violation type breaks down by race and gender. Descriptive numbers and the
generated charts live in `EDA_REPORT.md` once you run it.

### Dashboard (`app.py`)

- Filters: violation group, driver's state, vehicle type, gender, race,
  arrest type
- Summary tiles: total violations, accident-contributed count, seatbelt
  violations, personal injury cases, plus the most frequently cited
  make/model in the current selection
- Charts: violation categories, charge codes, race × gender, vehicle makes
  (treemap), vehicle type breakdown, arrest type outcomes
- Download the filtered slice as CSV

## Setup

```bash
pip install -r requirements.txt
```

## Running It

```bash
# 1. Clean the raw data (creates cleaned_traffic.parquet)
python clean_data.py

# 2. Generate the EDA report and charts (creates EDA_REPORT.md, eda_charts/)
python eda.py

# 3. Launch the dashboard
streamlit run app.py
```

The dashboard opens at http://localhost:8501.

## Recommendations

Based on `EDA_REPORT.md`:

- **Transit buses and school buses show a disproportionately high
  accident-contribution rate** relative to their share of stops. Worth a
  closer look even though the raw counts are small - a targeted inspection
  or training program for those fleets could be cheap to run and high value.
- **"Other" is the largest violation-group bucket** across every demographic
  group, which mostly means the keyword rules in `categorize_violation()`
  don't cover enough ground yet. Expanding that function (or moving to a
  proper text-classification pass) would sharpen every other chart in the
  dashboard.
- **To actually answer the hotspot/time-of-day questions this project was
  scoped for, the dataset needs a fuller export** with stop date, time, and
  location. The cleaning pipeline is already written to pick those up if
  they show up later.

## Troubleshooting

| Problem | Solution |
|---|---|
| `streamlit` command not found | Use `python -m streamlit run app.py` instead |
| `No module named 'plotly'` (or seaborn/pyarrow) | Run `pip install -r requirements.txt` |
| Error loading parquet file | Run `python clean_data.py` first |
| `eda.py` can't find the parquet file | Same - run `clean_data.py` before `eda.py` |
